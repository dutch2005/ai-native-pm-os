# Module 0 — Claude Code Foundations
## Build Your Operating Foundation Before Touching PM Work

---

> **The rule of this module:** You do not start any PM work until you've built the foundation.
> That means understanding how Claude Code works, what its modes are, how files connect to it, and how slash commands and skills extend it.

---

## The Ladder

This module is sequenced deliberately. Each lesson builds on the last.

```
0.1 → Install & choose your tier
0.2 → Understand Claude's modes (Chat / Projects / Code)
0.3 → Build your 4 core folders
0.4 → Write your 2 core files (CLAUDE.md + anti-patterns)
0.5 → Master slash commands and skills
0.6 → Connect your first tool (MCP/Connector)
0.7 → The PM AI mental model (agents, sub-agents, memory)
0.8 → Token economics — right model, right task
```

**Do not skip lessons.** Each one is a prerequisite for the next.
